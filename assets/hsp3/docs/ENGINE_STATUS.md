# تقرير التنفيذ والتكامل — مدير طباعة HSP3

## ما نُفذ
- الخط الأخضر في الرسمي العرضي والطولي، بلون `#176B45` وسمك `1.5mm`، مع إزاحة 10 مم عن الجانبين.
- طبقة نص فوق صورة الهيدر لكل من العرضي والطولي باسم إدارة التعليم واسم المدرسة؛ قيم افتراضية قابلة للتعديل من وضع التصميم.
- عنوان النافذة عنوان التقرير الحالي.
- وضعان عبر المحرك ذاته: `design` لإعداد المحتوى، و`viewer` لعرض التقرير المعتمد دون خيارات جانبية.
- مكونات توقيع الموظف ووكيل الشؤون المدرسية ومسؤول حضوري وقائمة ختامية ذات ثلاث نقاط مربعة ممتلئة افتراضيًا.
- بند القائمة الختامية جزء من المحتوى داخل مقسم الصفحات، وليس داخل الفوتر.

## الواجهة المقترحة للإضافة مستقبلًا
يُحمّل تطبيق حضوري سمارت برو ملفات `config.js`, `contents.js`, `composer.js`, `components.js`, `paginator.js`, `print-manager.js` وتنسيقاتها محليًا، ثم ينشئ واجهة `preview/print-manager.html` أو يدمج عناصرها داخل نافذة مضيفة.

```js
HSP3.openPrintPreview({
  mode: "viewer", // or "design"
  template: "official-landscape",
  educationAdministrationName: "اسم إدارة التعليم",
  schoolName: "اسم المدرسة",
  report: {
    title: "تقرير الموظفين",
    columns: ["اسم الموظف", "الحالة"],
    rows: [["اسم تجريبي", "منتظم"]],
    statistics: [{label:"عدد الموظفين", value:"١"}],
    signoff: {principal: "مدير المدرسة", showSignature: true, showStamp: true},
    extraComponents: [
      {kind:"bulletList", options:{items:["البند الأول","البند الثاني","البند الثالث"]}}
    ],
    minTailRows: 3
  }
});
```

وضع `viewer` مع `report` يستخدم بيانات التقرير المختارة دون تعديل المكونات، بينما يُظهر وضع `design` اللوحة الجانبية.

## مطابقة المكونات الأصلية
مرجع الفحص: `SmartProDigital/extension/features/print-engine/components/official_signoff_components.js`. المكوّنات الرسمية المؤكدة: مدير المدرسة، وكيل الشؤون المدرسية، ختم المدرسة، اطلاع الموظف.
مسمى «مسؤول حضوري» لم يُثبت بأنه تسمية ثابتة في الكود المستخرج؛ لذلك المسمى قابل للتمرير عبر `officerRole` أو `role`.

## حدود معروفة
- البيانات الحالية في صفحة المعاينة تجريبية. لا تُنقل صور توقيع أو ختم فعلية إلى ملفات Pages العامة.
- تصدير PDF يعتمد على نافذة المتصفح (Save as PDF).
- محرك التقسيم لا يدعم بعد تقسيم كتلة توقيعات وإحصاءات يتجاوز ارتفاعها صفحة كاملة.
- اختبارات GitHub Actions اختبارات ثابتة وبناء؛ لا تعادل اختبارًا بصريًا أو فحص PDF حقيقيًا.
