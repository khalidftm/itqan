# دليل إجراءات استخدام صفحة FTM وطباعتها

الصفحة: `ftm.html` — مدير الطباعة الجديد: `assets/hsp3/preview/itqan-print.html`.

## 1. تحديث بيانات إدارة التعليم والمدرسة وحفظها
1. افتح صفحة **FTM** من المتصفح والجهاز الذي تستخدم عليه ملف الإنجاز.
2. من القائمة الجانبية اختر **بيانات المدرسة**، أو زر **تحديث البيانات** في اللوحة الرئيسية.
3. اكتب اسم إدارة التعليم واسم المدرسة.
4. اضغط **حفظ البيانات**.
5. تحقق من ظهور الاسمين في الشريط التعريفي للصفحة، ثم افتح **طباعة ملف الإنجاز** لفحص ترويسة التقرير.

القيم الافتراضية في FTM:
- إدارة التعليم: **الإدارة العامة للتعليم بمنطقة مكة المكرمة**.
- المدرسة: **ابتدائية بحرة المجاهدين الخامسة ببحرة المجاهدين**.

**مهم:** تحفظ هاتان القيمتان في `localStorage` لهذا المستخدم داخل هذا المتصفح، ولا تستبدلان بيانات المدارس لجميع الحسابات في قاعدة النظام. يمكن إعادة تعديلهما من الزر نفسه.

## 2. تحديث معلومات المعلمة والسيرة الذاتية
1. افتح **السيرة الذاتية** من القائمة.
2. اضغط **تحرير وتحديث بطاقة السيرة الذاتية**.
3. حدّث المؤهل والجامعة والخبرة والرؤية والرسالة وسائر الحقول المتاحة.
4. اضغط زر الحفظ داخل النافذة.
5. تأكد من تحديث البطاقة. تظهر حالة النسخ السحابي في أسفل القائمة مستقلة عن تاريخ نشر إصدار الصفحة.

## 3. رفع شاهد أو تقرير أو وثيقة
1. اضغط **إضافة شاهد** في الشريط العلوي، أو افتح **رفع الملفات والشواهد**.
2. اختر ملفًا من الجهاز: `PDF` أو `Word` أو `Excel` أو `PowerPoint` أو صورة `PNG/JPG`.
3. حدد **قسم ملف الإنجاز**، ثم **نطاق المشاركة/الخصوصية**، ثم **معيار الأداء المرتبط**.
4. أدخل **عنوان الشاهد** و**وصفه والأثر التربوي**.
5. اضغط **حفظ الملف وتوثيق الشاهد الآن** وانتظر ظهور رسالة نجاح العملية.
6. افتح **سجل الشواهد والملفات** وتأكد من ظهور الملف وإمكانية معاينته أو تنزيله.

تحفظ المرفقات الفعلية محليًا في **IndexedDB**، وتُحفظ بياناتها الوصفية في **LocalStorage**. يظل كل جهاز/متصفح مستقلًا إلى أن تُفعّل مزامنة صحيحة وتختبر استعادتها. رفع «تقرير» هنا يعني إرفاق ملف تقرير كشاهد، ولا يعني تلقائيًا استخراج محتوى التقرير وإدراجه داخل كشف الطباعة.

## 3 مكرر. رفع ملف دون ربطه بالأداء أو الإنجاز
1. من شريط أعلى صفحة FTM اضغطي **رفع ملف مستقل**، أو افتحي قسم **الملفات غير المرتبطة** ثم اضغطي **رفع ملف جديد**.
2. اختاري أي ملف من جهازك (صورة، PDF، Word، Excel، فيديو، أو نوع آخر)، وأدخلي عنوانًا وملاحظة إذا رغبتِ.
3. اضغطي **حفظ دون ربط**. يُحفظ الملف فعليًا في خزنة IndexedDB ويُضاف إلى قائمة مستقلة خاصة بحساب المعلمة النشط.
4. افتحي **الملفات غير المرتبطة** لاستعراضه، والبحث باسمه، ومعاينته إذا كان PDF أو صورة مدعومة، أو تنزيله إذا كان نوعًا آخر.
5. لربطه لاحقًا، اضغطي **ربط** ثم حددي **ملف الإنجاز** واخترِي قسمًا، أو **الأداء الوظيفي** وحددي معيار الأداء المعني. اضغطي **تأكيد الربط**.
6. ينتقل سجل الملف إلى الشواهد المرتبطة ويختفي من القائمة المستقلة، **من دون رفع نسخة جديدة** أو تغيير محتوى الملف المحفوظ. ويمكن حذف الملف غير المرتبط نهائيًا من القائمة عند عدم الحاجة إليه.

**مهم:** تدخل الملفات غير المرتبطة في النسخ الاحتياطي التلقائي أيضًا دون الحاجة إلى ربطها، عند تفعيل اتصال مستودع GitHub خاص. تُحفظ مع حالة «غير مرتبطة» في بيانات النسخة السحابية، وتستخدم الملف الثنائي نفسه عند الربط لاحقًا دون تكرار رفعه. عند عدم إعداد اتصال خاص، يبقى الحفظ محليًا فقط؛ لا تمسحي بيانات المتصفح قبل تأمين نسخة احتياطية للملفات المهمة.

## 4. تحديث معايير الأداء
1. افتح **معايير الأداء**.
2. راجع البنود والدرجات والشواهد المرتبطة بها.
3. عدّل ما يلزم واضغط **حفظ واعتماد التقييم الذاتي للمعلمة**.
4. تحقق من تحديث المؤشرات العلوية.

## 5. مكتبة المكونات
1. افتح **مكتبة المكونات**.
2. اختر النطاق أو استخدم المكونات المشتركة المعروضة.
3. اضغط زر تضمين المكون الذي تريد إضافته، أو **إنشاء مكون أو وثيقة جديدة**.
4. أدخل البيانات المطلوبة واضغط حفظ، ثم تحقق من تغيّر عداد المكونات.

## 6. طباعة كشف الشواهد بأحد قوالب HSP3 الأربعة
1. اضغط **طباعة ملف الإنجاز** من الشريط العلوي في صفحة FTM.
2. تفتح **معاينة المستخدم دون لوحة خيارات التقرير**.
3. من شريط أدوات الطباعة، اختر أحد القوالب: **رسمي طولي، مصوّر طولي، رسمي عرضي، مصوّر عرضي**.
4. استخدم **احتواء العرض/الصفحة** أو التكبير والتصغير عند المعاينة من الكمبيوتر أو الجوال.
5. اضغط **طباعة**، أو **تصدير PDF** ثم اختر **حفظ كملف PDF** في نافذة طباعة المتصفح.
6. راجع الهيدر والفوتر والاسم والمدرسة وتقسيم الصفحات قبل اعتماد المطبوع. اضغط **إغلاق** للعودة مباشرة إلى صفحة FTM دون المرور بصفحة وسيطة.

يستخدم النص داخل الأوراق **خط تجوال (Tajawal)**، بينما تستخدم واجهة التحكم **كايرو (Cairo)**. جميع الأوراق A4 وفق اتجاه القالب المختار. **كشف HSP3 الحالي يطبع بيانات الشواهد وعناوين المرفقات والإحصاءات، ولا يدمج صفحات PDF/Word المرفوعة داخل التقرير نفسه.**

## 7. النسخ الاحتياطي التلقائي إلى مستودع GitHub خاص

1. أنشئ مستودع GitHub منفصلًا مضبوطًا على **Private** (ليس المستودع العام `khalidftm/itqan`).
2. من GitHub أنشئ رمز وصول **Fine-grained PAT** محددًا لهذا المستودع فقط، وبصلاحية **Contents: Read and write**، بعد الحصول على تصريح الجهة المختصة قبل معالجة بيانات حقيقية.
3. افتح صفحة FTM واختر **إعداد النسخ السحابي** من القائمة الجانبية، وأدخل مالك المستودع واسمه ورمز الاتصال للجلسة الحالية.
4. يختبر البرنامج أولًا أن المستودع **خاص** وأن الرمز يسمح بالكتابة؛ إذا لم يجتز الاختبار لا تُرفع أي ملفات.
5. يشمل النسخ التلقائي **الشواهد المرتبطة والملفات غير المرتبطة** من حساب المعلمة النشط؛ ويُحفظ وصف حالة الربط في ملف `snapshot.json` لتظل الملفات غير المرتبطة متميزة عن الشواهد.
6. بعد نجاح الإعداد، **كل عملية حفظ شاهد أو ملف مستقل أو تحديث بيانات تقوم بإطلاق النسخ تلقائيًا** في الخلفية أثناء فتح الصفحة، دون زر مزامنة أو زر رفع إلى السحابة. يبدأ حفظ الملف في IndexedDB أولًا، ثم تُرفع نسخته إلى `uploads/ftm/{userId}/` وتُحدّث نسخة بيانات المستخدمة في `data/ftm/{userId}/snapshot.json`.
7. تابع حالة النسخ السحابي أسفل القائمة الجانبية: محلي فقط، جارٍ الرفع، اكتمل النسخ، أو حدث خطأ. عند الانقطاع تبقى البيانات المحلية، ويُعاد المحاولة مع تعديل لاحق أو إعادة الاتصال.
8. ينتهي رمز الاتصال بانتهاء جلسة المتصفح، ولا يُحفظ كاعتماد دائم. تحتاج المستخدمة إلى إعادة إدخاله في جلسة جديدة؛ لا يمكن ضمان مزامنة آلية مستمرة دون خدمة حسابات آمنة في الخلفية.

**حدود مهمة:** هذا التنفيذ يقدم **نسخًا احتياطيًا تلقائيًا من المتصفح إلى المستودع الخاص**، ولا يقدم استرجاعًا تلقائيًا أو دمجًا آمنًا بين عدة أجهزة حتى الآن. يجب عدم اعتبار نسخ GitHub ضمانًا لاستعادة بيانات عدة أجهزة دون اختبار مستقل. لا يُنصح باستخدام الرموز داخل تطبيق متصفح عام للبيانات الحساسة، حتى مع `sessionStorage`؛ يلزم حل خلفي وتفويض مناسب قبل الإنتاج.

## 8. تاريخ آخر تحديث
يعرض أسفل القائمة الجانبية **تاريخ ووقت آخر نشر ناجح وفق GitHub Actions / pages build and deployment** بتوقيت السعودية، ويقارن SHA الالتزام الذي تم نشره بآخر التزام على فرع `main`. تظهر حالة النشر إن كان إصدار أحدث قيد النشر أو فشلت المهمة. لا علاقة لهذا الوقت بحفظ بيانات المعلمة، وقد يتأخر تحديث المتصفح بسبب ذاكرة التخزين المؤقت. اضغط «↻» لإعادة التحقق.

## 9. استخدام الجوال
- اضغط زر القائمة ☰ لفتح التنقل، واضغط خارجها أو Escape لإغلاقها.
- يفتح مدير الطباعة بكامل شاشة الجوال تقريبًا، وتظهر أدواته بتخطيط مرن.
- عند تصغير ورقة A4 للمعاينة، يبقى مقاسها الأصلي محفوظًا عند الطباعة أو تصدير PDF.
- يلزم فحص بصري فعلي على Chrome/Android وSafari/iOS عند توافرهما قبل اعتماد المطبوع.


### تنبيه خصوصية مهم
التنفيذ المحدّث للنسخ الاحتياطي يستخدم GitHub API من المتصفح ويحتفظ برمز الوصول في SessionStorage لجلسة المتصفح فقط، وليس في LocalStorage الدائم. ومع ذلك تستطيع السكربتات التي تعمل على نفس الأصل الوصول إليه خلال الجلسة. وجود الرمز في متصفح شخص آخر أو جهاز غير موثوق قد يسمح باستخدام صلاحياته. يفضّل قبل حفظ بيانات حقيقية نقل عملية المزامنة إلى خدمة خلفية مؤمنة بآلية حسابات وصلاحيات مستقلة، وعدم الاعتماد على رمز وصول شخصي في الواجهة العامة. لا ترفع بيانات حساسة إلى `main` أو `uploads/` في المستودع العام.
